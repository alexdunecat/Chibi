# PF1 Chat Images

Модуль для Foundry VTT v11 (проверено на 11.315) и системы Pathfinder 1e (10.8).
Подменяет картинку в сообщениях чата на заранее подготовленные изображения по типу действия.
Сами сообщения не меняются: подмена делается при отрисовке, поэтому модуль можно выключить в любой момент, и чат станет обычным.

## Установка

**По ссылке (после первого релиза):** в Foundry откройте **Дополнения → Установить модуль** и вставьте в поле «Ссылка на манифест»:

```
https://github.com/alexdunecat/Chibi/releases/latest/download/module.json
```

**Вручную:**

1. Скопируйте папку `pf1-chat-images` целиком в `Data/modules/` (рядом с другими модулями).
   Должно получиться `Data/modules/pf1-chat-images/module.json`.
2. Перезапустите Foundry или вернитесь в меню и снова зайдите в мир.
3. В мире: **Настройки игры → Управление модулями → PF1 Chat Images** и включите его.

## Куда класть картинки

По умолчанию модуль ищет файлы в папке `Data/chat-images/` (создайте её сами, рядом с папками `modules` и `worlds`).
Имена файлов:

| Категория | Файл по умолчанию |
|---|---|
| Каст заклинания | `chat-images/spell.webp` |
| Атака ближнего боя | `chat-images/melee.webp` |
| Атака дальнего боя | `chat-images/ranged.webp` |
| Критический успех | `chat-images/critSuccess.webp` |
| Критический провал | `chat-images/critFailure.webp` |
| Бросок знаний | `chat-images/knowledge.webp` |
| Прочие навыки | `chat-images/skill.webp` |
| Спасбросок воли | `chat-images/saveWill.webp` |
| Спасбросок стойкости | `chat-images/saveFort.webp` |
| Спасбросок реакции | `chat-images/saveRef.webp` |
| Применение предмета | `chat-images/itemUse.webp` |

Можно использовать любые форматы (png, jpg, webp, svg) и любые пути: в **Настройках модуля** у каждой категории есть поле с кнопкой выбора файла.
Если поле пустое, картинка этой категории не меняется. Если файла по пути нет, остаётся обычная картинка системы.

Картинки лучше держать не внутри папки модуля: при обновлении модуля папка перезаписывается.

## Как определяется категория

- **Каст заклинания**: любое использование предмета типа «заклинание» (в том числе заклинания с атакой).
- **Ближний бой**: действие с типом атаки ближнего боя (оружие, заклинание, боевой приём).
- **Дальний бой**: действие с типом атаки дальнего боя или метательное.
- **Знания**: навыки «Знание (…)», остальные навыки идут в «Прочие навыки».
- **Спасброски**: воля, стойкость, реакция.
- **Применение предмета**: использование предмета из инвентаря (оружие, снаряжение, расходники, добыча, контейнеры), если это не атака. Например, зелье, жезл, свиток.
- **Крит**: естественная 20 или 1 на d20 в атаке, навыке или спасброске показывает картинку крита вместо обычной. Если в серии атак есть хоть одна 20, показывается успех. «Взять 10/20» критом не считается. Отключается в настройках.

Не трогаются: инициатива, проверки характеристик, БМА, уровень заклинателя, концентрация, способности без атаки (черты, классовые особенности).

## Настройки

- **Чьи сообщения менять**: только сообщения игроков (по умолчанию), сообщения персонажей игроков (даже если бросал ГМ), или все.
- **Крит важнее категории**: вкл/выкл.
- **Размер картинки**: от 24 до 256 px, по умолчанию 48.

В карточках атак, заклинаний и предметов подменяется иконка предмета в шапке карточки. У бросков навыков и спасбросков своей картинки нет, поэтому модуль вставляет картинку в начало сообщения.

## Разработка

- `npm ci && npm test` — проверка определения категорий на заглушках Foundry (без запуска самого Foundry).
- Релиз: поднимите `version` в `module.json` и запушьте тег вида `v1.0.1` (`git tag v1.0.1 && git push origin v1.0.1`). Workflow `Release` сам подставит версию, соберёт `module.zip` и опубликует релиз с `module.json` и `module.zip`, после чего Foundry увидит обновление.
